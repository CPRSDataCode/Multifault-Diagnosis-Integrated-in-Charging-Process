# A-Two-Stage-Multifault-Diagnosis-Method-for-Lithium-Ion-Batteries-Integrated-in-Charging-Process

This repository contains the dataset and source code associated with the research paper "A Two-Stage Multifault Diagnosis Method for Lithium-Ion Batteries Integrated in Charging Process", published in Cell Reports Physical Science.

The “Data” folder contains the raw experimental data. For ISC faults, the value following the underscore represents the short-circuit resistance in Ω. For PCC faults, the value following the underscore represents the series resistance in mΩ.
The “Code” folder contains the source code. The subfolder names correspond to the proposed two-stage diagnosis method. Please note that the “Refined Diagnosis of Minor ISC in the Second Stage” folder contains the extracted raw data for the final 800 seconds in the charging process, saved as CSV files.
